# vbnet-ls

`vbnet-ls` is the command-line language server for VB.NET Language Support.

## Usage

Run over stdio (recommended for editor LSP clients):

```bash
vbnet-ls --stdio
```

Named pipe mode is also supported:

```bash
vbnet-ls --pipe
```
