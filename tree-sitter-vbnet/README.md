# tree-sitter-vbnet

Authoritative Tree-sitter grammar for VB.NET maintained by DNAKode.

This grammar starts with conservative VB.NET coverage required by the Zed
adapter fixtures and will expand toward full practical VB.NET syntax. It is not
derived from the previous bootstrap grammar dependency.

The authoritative source lives in `DNAKode/vbnet-lsp/tree-sitter-vbnet`.
`DNAKode/tree-sitter-vbnet` is a downstream mirror used so Zed and other
Tree-sitter consumers can clone the grammar from a standalone public
repository.
